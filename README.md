# usachTarea4
Trabajo en pareja para aprender a utilizar git

# 1. Creas y te cambias a la nueva rama
git checkout -b mi-nueva-funcionalidad

# (Aquí editas tus archivos, programas y guardas en tu editor)

# 2. Verificas el estado de tus archivos (Opcional pero recomendado)
git status

# 3. Agregas todos los cambios al escenario de preparación
git add .

# 4. Confirmas los cambios en tu historial local
git commit -m "Implementa la nueva funcionalidad X"

# 5. Envías la rama por primera vez al servidor remoto
git push -u origin mi-nueva-funcionalidad
